
# BIOS 640 Week 4 Assignment

This repository contains the work completed for the BIOS 640 Week 4 assignment.

## Repository Structure

- `data/` — datasets used in the analyses.
- `code/` — R and R Markdown source files.
- `figures/` — figures generated during the analyses.
- `reports/` — rendered reports and other written outputs.
- `dashboard/` — files used to create and display the dashboard.

## Reproducibility

The analysis uses relative file paths and `here()` where appropriate so that the work can be reproduced after cloning the repository.

Rendered outputs are included in the repository so that the results can be reviewed without rerunning the analyses.
